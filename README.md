# FourSolutions
**Proyectos a tu medida**

## Descripción
FourSolutions es una consultora de desarrollo de software formada por estudiantes de
TNS Analista Programador del CFT de la Región de La Araucanía. En este repositorio
presentamos nuestro equipo y el proyecto **Sistema de Gestión de Citas para la Clínica
Veterinaria MyKan** 🐾, una solución web que digitaliza la gestión de pacientes, citas,
fichas clínicas y pagos, que hoy la clínica realiza de forma manual.

## Propuesta de valor
Somos un equipo de desarrolladores que ayudamos a pequeñas y medianas organizaciones
a dejar atrás los procesos manuales mediante sistemas web a medida, simples de usar,
seguros y pensados para su forma de trabajar.

## Servicios
1. **Análisis y levantamiento de requerimientos:** nos reunimos con el cliente, estudiamos sus procesos y definimos qué necesita realmente el sistema.
2. **Diseño de experiencia e interfaz (UX/UI):** creamos prototipos y pantallas fáciles de usar para personas sin conocimientos técnicos.
3. **Desarrollo de sistemas web a medida:** construimos el sistema completo, desde la base de datos y la lógica (backend) hasta las pantallas (frontend), con seguridad y respaldos incluidos.
